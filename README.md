# Caesar Cipher in Python

This is a simple Python program that encrypts and decrypts messages using the Caesar Cipher algorithm.

## 🔐 Features

- Encrypt messages with a shift value.
- Decrypt messages using the same shift value.
- Handles both uppercase and lowercase letters.
- Preserves non-alphabet characters (e.g., punctuation and spaces).

## 📦 Requirements

- Python 3.x

## ▶️ Usage

1. Clone the repository or copy the `caesar_cipher.py` file.
2. Run the script:

```bash
python caesar_cipher.py
